吉易是一款年轻化的东方生活方式小程序。项目使用微信小程序原生 WXML、WXSS、JavaScript 开发，并基于 [`lunar-javascript`](https://github.com/6tail/lunar-javascript) 在客户端完成公历、农历、黄历、节气、传统节日、四柱八字与择日计算。

项目没有云函数、云数据库、后端服务或远程业务 API。个人资料、偏好、留印和计划均在用户设备本地处理与保存。

## 核心功能

- **今日黄历**：日期、农历、宜忌、冲煞、值神、吉时和每日提醒
- **四柱八字**：根据出生日期与时间生成四柱、日主、五行与个人日期参考
- **专业日课**：展示建除、十神、神煞、星宿、九星、胎神、日禄与彭祖百忌
- **好日子择日**：按婚嫁、搬家、提车、出行、开业、自定义事项与时间范围推荐日期
- **日历浏览**：按月查看农历、节气、传统节日、每日等级、留印和计划
- **计划闭环**：保存候选日期，管理待进行、今日和已结束计划
- **术语切换**：支持现代生活化文案与经典黄历命理术语切换
- **主题与海报**：朱砂、松青、黛蓝、金桂四套主题，本地生成东方视觉分享海报

## 技术特点

- 微信小程序原生开发，无跨端框架依赖
- `lunar-javascript` 本地历法计算
- 四柱、十神、五行、冲合与神煞规则在客户端运行
- 日期推荐支持事项、范围、工作日、周末、时段和排除日期等约束
- Canvas 2D 本地绘制与导出分享海报
- 本地缓存保存资料、主题、留印和计划
- 无登录、无交易、无广告 SDK、无服务端数据上传

## 本地运行

1. 克隆仓库并安装依赖：

   ```bash
   git clone https://github.com/BryceYuuu/jiyi.git
   cd jiyi
   npm install
   ```

2. 在微信开发者工具中导入仓库根目录。
3. 执行“工具 → 构建 npm”。
4. 使用自己的小程序 AppID，或选择测试号进行本地调试。
5. 点击“编译”或“预览”查看效果。


## 隐私与使用边界

- 昵称、生日、出生时间、生肖、留印、偏好和计划仅保存在微信本地缓存。
- 相册能力仅在用户主动选择头像或保存海报时使用。
- 黄历、八字、命理和择日内容用于传统文化研究、产品设计与生活参考，不构成医疗、法律、财务或其他专业建议，也不承诺现实结果。
