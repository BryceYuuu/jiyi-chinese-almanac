# 吉易公开素材清单

公开仓库建议准备一套统一视觉素材。所有截图使用同一台设备、同一主题和同一字体缩放，隐藏微信账号、体验二维码、AppID、昵称与真实生日等个人信息。

## 必备素材

| 素材 | 建议尺寸 | 比例 | 内容 |
|---|---:|---:|---|
| 品牌图标 | 1024 × 1024 px | 1:1 | “吉易”印章或品牌符号，米白底，主体居中，四周保留约 12% 安全区 |
| GitHub 社交封面 | 1280 × 640 px | 2:1 | 左侧品牌名与“纯前端黄历·八字·择日小程序”，右侧展示三个核心页面 |
| README 首图 | 1600 × 900 px | 16:9 | 产品总览，组合首页、专业黄历、日历和海报，不放二维码 |
| 手机页面截图 | 1170 × 2532 px | 约 9:19.5 | 原始真机截图，统一机型、主题和状态栏时间 |
| 功能拼图 | 1600 × 1200 px | 4:3 | 由 3 至 4 张手机截图组成，用于快速解释产品能力 |
| 海报样例 | 1080 × 1440 px | 3:4 | 日光、山行、书页三种风格各一张，日期、标题和构图均有差异 |

## 推荐截图内容

1. **今日友好版**：日期、农历、今日建议、每日灵感与未来三天完整可见。
2. **今日专业版**：宜忌、冲煞、值神、吉时、十神和神煞体现专业信息密度。
3. **四柱八字**：四柱、日主、五行与个人日期参考，使用演示资料而非真实个人信息。
4. **月历页面**：同屏出现节气、传统节日、每日状态、留印和计划标记。
5. **好日子择日**：事项、时间范围、时段条件、推荐分数与查看依据。
6. **主题切换**：同一页面并列展示朱砂、松青、黛蓝、金桂四种主题。
7. **分享海报**：三种不同背景构图与信息层级，避免只换色、不换画面。

## 可选动态素材

| 素材 | 建议规格 | 内容 |
|---|---|---|
| README 演示 GIF | 720 × 1280 px，9:16，8 至 15 秒，建议小于 10 MB | 今日 → 专业版 → 日历 → 好日子 → 保存计划 |
| 演示视频 | 1080 × 1920 px，9:16，20 至 40 秒 | 展示术语切换、主题切换、择日和海报生成 |

## 视觉要求

- 背景使用米白、宣纸肌理或克制山水素材，避免大面积高饱和颜色。
- 截图保持真实，不增加当前代码中不存在的联网服务或付费功能。
- 专业术语可以保留，但不要使用“保证准确”“预测结果”等承诺性文案。
- 不公开开发者工具二维码、体验版二维码、AppID、真实头像、真实生日或测试账号。
- 图片导出优先使用 PNG；照片型大背景可使用 85% 至 90% 质量的 JPG。

## 最小交付组合

如果先做一版，准备以下 7 张图即可：

- 1 张 1:1 品牌图标
- 1 张 2:1 GitHub 社交封面
- 4 张手机截图：今日友好版、今日专业版、日历、好日子
- 1 张 4:3 海报与主题拼图
