# Public Assets / 公开素材

本目录保存 GitHub README、仓库社交预览和产品介绍使用的公开视觉素材。运行时不会打包 `docs/`，因此这些图片不增加微信小程序上传包体积。

| File | Size | Usage |
|---|---:|---|
| `jiyi-logo.png` | 512 × 512 | GitHub README Logo、头像与品牌识别 |
| `jiyi-chinese-almanac-cover.jpg` | 1600 × 800 | README 首图、GitHub Social Preview |
| `jiyi-product-showcase.jpg` | 1600 × 900 | 产品总览与项目介绍 |
| `jiyi-daily-huangli.jpg` | 720 × 1556 | 今日黄历 / Daily Huangli |
| `jiyi-lunar-calendar-solar-terms.jpg` | 720 × 1556 | 农历节气 / Lunar Calendar |
| `jiyi-bazi-four-pillars.jpg` | 720 × 1556 | 四柱八字 / Bazi & Four Pillars |
| `jiyi-auspicious-date-selection.jpg` | 720 × 1556 | 择日推荐 / Date Selection |
| `jiyi-feature-overview.jpg` | 1440 × 1080 | 功能总览 / Feature Overview |
| `jiyi-brand-poster.jpg` | 900 × 1200 | 品牌介绍 / Brand Poster |

## Publishing Notes

- GitHub Social Preview 推荐使用 `jiyi-chinese-almanac-cover.jpg`。
- 图片不包含二维码、AppID、测试账号或真实个人资料。
- README 使用英文文件名和中英双语 `alt` 文本，便于搜索引擎理解图片语义。
- 大图统一使用 86% 至 88% JPEG 质量，在清晰度与仓库加载速度之间取平衡。
