# 「今日吉历」微信小程序 · Vibe Coding 完整开发文档

> **用法**：把本文档全文粘贴给 AI 编程工具（Claude Code / Cursor 等）作为项目上下文，然后按**第 9 章**的分步提示词逐条下任务。**第 8 章**是最终嵌入云函数里的运行时 AI 提示词。

## 1. 产品定位与合规红线（须写进代码注释，AI 编码时全程遵守）

- **产品名**：今日吉历（备选：知历、吉日历。一律避开"算命 / 占卜 / 看相"字样）
- **一句话定位**：年轻人的国潮黄历——查宜忌、挑吉日、抽签、看传统命理文化解读
- **小程序类目**：工具 > 信息查询（或 工具 > 日历）。不要选宗教、风水类目

**硬性规则（所有页面与 AI 输出必须遵守）：**

1. 全站文案禁用"算命、占卜、大师、改运、化解、破财消灾"等词，统一用"传统文化解读、运势参考、民俗内容"
2. 每个测算类页面底部固定免责声明：`本内容基于传统民俗文化由 AI 生成，仅供娱乐参考，不构成任何决策依据。`
3. AI 输出禁用恐吓性、绝对化断言（约束已写进第 8 章各 prompt）
4. 黄历宜忌、八字排盘**全部由 lunar-javascript 精确计算**，严禁让大模型生成或推算任何历法数据
5. DeepSeek API Key 只存放在云函数环境变量中，绝不出现在小程序前端代码里

## 3. 页面结构

### 3.0 路由总览

```
pages/
  index/index        今日（tab1）黄历首页
  almanac/detail     黄历详情（任意日期）
  auspicious/index   择吉（tab2）吉日查询
  sign/index         每日一签
  zodiac/index       生肖运势
  bazi/index         测算（tab3）测算大厅
  bazi/input         八字信息录入
  bazi/report        报告展示（免费预览+付费解锁）
  hehun/input        合婚信息录入（v1.1 再做）
  profile/index      我的（tab4）
  poster/index       今日海报分享
  pay/result         支付结果
  legal/disclaimer   免责声明 / 用户协议
```

### 3.1 今日（首页，tab1）

布局自上而下：

1. **日期区**：超大衬线数字（如"7"），旁列"2026年7月 · 星期二 / 农历五月廿三 · 丙午年"，右上角小字显示"距小暑还有X天"
2. **宜忌卡**：左侧红色"宜"印章 + 词条胶囊流，右侧墨灰"忌"章 + 词条流（各最多显示 8 条，点"展开"看全部）
3. **信息网格 2×3**：冲煞 / 值神(标注黄道或黑道) / 彭祖百忌 / 财神方位 / 喜神方位 / 福神方位
4. **吉时条**：12 时辰横向滚动，黄道时辰用鎏金色高亮
5. **双入口卡**：「抽今日签」「生肖运势」
6. 底部按钮：生成今日海报

交互：左右滑动切换前后一天；点日期弹出日历可跳任意日期（进 almanac/detail）。
数据来源：前端 lunar-javascript 实时计算，**零后端请求**。

### 3.2 择吉（tab2）

表单：事项（宫格单选）+ 时间范围（未来 30/60/90 天）+ 可选「避开冲我生肖」（选生肖）。

**事项 → 宜关键词映射（写死在前端常量）：**

```js
const YI_MAP = {
  '领证/结婚': ['嫁娶', '纳采', '订盟'],
  '搬家':      ['移徙', '入宅'],
  '开业':      ['开市', '立券', '交易'],
  '提车':      ['纳财', '出行', '交易'],
  '装修':      ['修造', '动土'],
  '出行':      ['出行'],
  '签约':      ['立券', '交易', '订盟']
};
```

筛选逻辑：循环范围内每一天 → `getDayYi()` 包含任一关键词，且 `getDayJi()` 不包含 → 若勾选了生肖过滤，`getDayChongDesc()` 不含所选生肖字 → 输出吉日卡片（公历/农历/星期/命中的宜词条/冲煞/值神），值神为黄道的加金边「黄道吉日」角标。全部前端计算。

结果页顶部小字：吉日为传统民俗参考。

### 3.3 每日一签

仪式感页面：签筒 CSS 摇晃动画约 1.5s → 调云函数 `getSign` → 翻牌展示：等级章（上上/上吉/中吉/中平/下）、签名、**竖排四句签诗**（writing-mode: vertical-rl）、典故、白话解、分领域一句解（事业/姻缘/财帛/健康）。

可选输入「想问之事」（20 字内，云端过 msgSecCheck）→ 调 `interpretSign` 云函数返回 AI 个性化解读，**每人每日 1 次免费**。

规则：每人每天固定一支（重复进入显示同一支，幂等逻辑在云端）；页面配分享海报按钮。

### 3.4 生肖运势

12 生肖宫格 → 详情页：五维分数（综合/事业/财运/感情/健康，1-5 分用铜钱图标 ◉◉◉○○）+ 80-100 字运势短文 + 今日建议 + 幸运色/数字/方位。数据读集合 `daily_zodiac`（云函数每日定时生成）。首次进入引导用户选自己的生肖并存入 `users.zodiac`，下次直达。

### 3.5 测算大厅（tab3）

三张服务卡：八字详批（¥19.9，首单 ¥9.9）、2026 流年运势（¥9.9）、合婚（¥29.9，v1.1 上线）。每卡列 3 条卖点 + 样例报告截图位。底部免责声明 + 「我的报告」入口。

### 3.6 八字录入（bazi/input）

字段：称呼（昵称即可，云端 msgSecCheck 校验）、性别、公历/农历切换、年月日 picker（1940 至今年）、时辰 picker（子时 23-1 点 … 亥时 21-23 点，外加「时辰不详」）、出生城市（选填，v1 不做真太阳时校正）。

时辰不详时提示「将按三柱分析，精度略降」。提交 → 写入 `birth_profiles` → 跳报告页并触发生成。

### 3.7 报告页（bazi/report）

状态机：`generating`（水墨加载动画 + 文案轮播"排盘中… / 推演五行中… / 撰写解读中…"，每 3 秒轮询）→ `done`。

展示：封面（称呼 / 四柱干支牌 / 五行计数条 / 一句话 summary）→ sections 手风琴列表。**免费部分：命局总览**；其余 section 标题可见、正文区显示模糊占位 + 锁图标 → 引导支付解锁。

**安全要点：未支付时云函数只下发 summary + overview，其余 section 的正文一律不返回前端**（防抓包白嫖），解锁后重新拉取。

页脚：免责声明 + 「本报告由 AI 生成」标识。

### 3.8 我的（tab4）

默认头像昵称、我的生日档案（增删）、我的报告列表、「明日宜忌」订阅开关（wx.requestSubscribeMessage）、免责声明、联系客服（客服会话按钮）。

## 6. 云函数设计

| 云函数 | 触发方式 | 职责 |
|---|---|---|
| login | 前端 | 返回 openid，upsert users |
| getSign | 前端 | 查 user_signs 当日记录，无则从 signs 随机取一条写入并返回（幂等） |
| interpretSign | 前端 | 校验每日 1 次 → msgSecCheck(question) → 拼 8.3 prompt 调 DeepSeek → 结果存 user_signs.aiAnswer |
| generateBaziReport | 前端 | 读档案 → lunar-javascript 排盘 → 建 reports(status=generating) → 拼 8.1 prompt 调 DeepSeek(JSON 模式) → 解析入库置 done；失败重试 1 次后置 failed |
| getReport | 前端 | 按 isPaid 裁剪：未付款只返回 summary + overview + 其余 section 的标题 |
| createOrder | 前端 | 读 config 价格（不信前端传参）→ 建 orders → cloudPay 统一下单 → 返回支付参数 |
| payCallback | 支付回调 | 验单 → orders 置 paid → 对应 report.isPaid=true |
| dailyCron | 定时触发器 `0 30 0 * * * *`（每日 00:30） | 拼 8.2 prompt 生成当日 12 生肖运势写入 daily_zodiac；给 subDaily 用户发「今日宜忌」订阅消息 |

**安全要点**：DEEPSEEK_KEY 放云函数环境变量；所有用户文本输入过 `security.msgSecCheck`；价格金额一律以 config 为准。

## 7. lunar-javascript 关键 API 速查（防幻觉；以此为准，遇到不确定的方法先 console.log 自查，官方文档 6tail.cn/calendar/api.html）

```js
const { Solar, Lunar } = require('lunar-javascript');

// ============ 黄历（首页 / 择吉） ============
const solar = Solar.fromYmd(2026, 7, 7);       // 也可 Solar.fromDate(new Date())
const lunar = solar.getLunar();

lunar.getYearInGanZhi();        // '丙午'  年干支
lunar.getMonthInGanZhi();       // 月干支
lunar.getDayInGanZhi();         // 日干支
lunar.getMonthInChinese();      // '五'
lunar.getDayInChinese();        // '廿三'
lunar.getYearShengXiao();       // '马'
lunar.getDayYi();               // ['嫁娶','祭祀',...]  宜
lunar.getDayJi();               // ['开市',...]        忌
lunar.getDayChongDesc();        // 冲煞描述（含被冲生肖字，用于择吉过滤）
lunar.getDaySha();              // '南'  煞方
lunar.getDayTianShen();         // '青龙' 值神
lunar.getDayTianShenType();     // '黄道' / '黑道'
lunar.getPengZuGan();           // 彭祖百忌·天干句
lunar.getPengZuZhi();           // 彭祖百忌·地支句
lunar.getDayPositionCaiDesc();  // '正北' 财神方位
lunar.getDayPositionXiDesc();   // 喜神方位
lunar.getDayPositionFuDesc();   // 福神方位
lunar.getJieQi();               // 当天是节气则返回名称，否则空串
lunar.getNextJieQi().getName(); // 下一个节气名（做倒计时）
lunar.getTimes();               // 12 时辰对象数组（干支/天神吉凶，做吉时条）

// 逐日循环建议：new Date 加一天，再 Solar.fromDate(d)，最稳

// ============ 八字（测算） ============
const s2 = Solar.fromYmdHms(1998, 8, 20, 14, 0, 0); // 时辰不详可暂用 12 点占位并在报告注明
const ec = s2.getLunar().getEightChar();

ec.getYear(); ec.getMonth(); ec.getDay(); ec.getTime();   // 四柱干支，如 '戊寅'
ec.getDayGan();                                            // 日主（日元）
ec.getYearWuXing(); // 及 getMonthWuXing / getDayWuXing / getTimeWuXing  各柱五行
ec.getYearShiShenGan(); ec.getMonthShiShenGan(); ec.getTimeShiShenGan(); // 十神
ec.getYearNaYin();  // 纳音（各柱同理）

const yun = ec.getYun(1);        // 参数：1 男，0 女
yun.getStartYear();              // 起运年份
const daYun = yun.getDaYun();    // 大运数组
daYun[1].getStartAge();          // 起始年龄
daYun[1].getGanZhi();            // 大运干支
```

**五行统计不要找 API，自己写映射表数出来（云函数里实现）：**

```
天干：甲乙=木  丙丁=火  戊己=土  庚辛=金  壬癸=水
地支：寅卯=木  巳午=火  申酉=金  亥子=水  辰戌丑未=土
```

四柱共 8 个字逐一归类计数，得到 金/木/水/火/土 各几个，随排盘数据一起传给 AI。

## 8. 运行时 AI 提示词库（原样嵌入云函数）

**统一调用参数**：`POST https://api.deepseek.com/chat/completions`，`model: "deepseek-chat"`，`temperature: 0.9`，`response_format: {"type":"json_object"}`，max_tokens 见各条。解析前先 trim 并容错去掉可能出现的 \`\`\`json 围栏。

### 8.1 八字详批（max_tokens: 4000）

**system：**

```
你是一位深耕中国传统命理文化的研究者，笔名"清源先生"。你熟悉四柱八字、五行生克、十神与大运，但你始终以传统文化科普与人生参考的视角进行解读，而非宿命论断言。

写作原则：
1. 只依据用户消息中提供的排盘数据进行分析，排盘数据已由程序精确计算，禁止自行推算或修改任何干支、五行。
2. 语气温和、具体、有画面感，像一位睿智长者与晚辈聊天。可以使用五行、十神等术语，但每次使用后立刻用一句白话解释。
3. 多谈倾向与建议，少下绝对结论。禁用词："必定、注定、大凶、血光、灾祸、劫难、克夫、克妻、短命、破财"等一切恐吓性、绝对化表述。
4. 涉及健康只做作息与情绪层面的养生提示，并提醒"身体不适请咨询医生"；涉及财富只谈心态与做事风格倾向，不给出任何具体投资建议。
5. 不推销任何"化解、改运、转运物品"类服务或商品。
6. 整体基调：扬长为主、提醒为辅，每个板块用一条可执行的行动建议收尾。
7. 严格输出 JSON 对象，不要输出 markdown 代码块标记或 JSON 以外的任何文字。

输出格式：
{
  "summary": "一句话概括命局气质，30字以内，用于报告封面",
  "sections": [
    {"id":"overview","title":"命局总览","content":"..."},
    {"id":"personality","title":"性格与天赋","content":"..."},
    {"id":"career","title":"事业发展","content":"..."},
    {"id":"wealth","title":"财富格局","content":"..."},
    {"id":"love","title":"感情婚姻","content":"..."},
    {"id":"health","title":"健康养生","content":"..."},
    {"id":"fortune","title":"未来三年运势展望","content":"..."},
    {"id":"advice","title":"综合建议","content":"..."}
```

## 10. 上线检查清单

1. **主体**：个人主体可先上免费版（黄历/择吉/抽签/生肖）；开通支付必须升级为个体工商户或企业主体并开微信支付商户号
2. **类目与名称**：工具 > 信息查询（或日历）；名称、简介、截图不出现算命/占卜字样
3. **隐私合规**：在小程序后台配置《用户隐私保护指引》，声明收集"出生日期、昵称"；app.json 开启隐私相关配置
4. **内容安全**：所有用户输入（称呼、所问之事）云端过 security.msgSecCheck；测算页与报告页带免责声明 + "AI 生成"标识
5. **生成式 AI 合规**：调用已完成备案的大模型 API（如 DeepSeek），页面明确标注内容由 AI 生成、仅供娱乐参考
6. **订阅消息**：在后台申请"每日提醒"类模板，模板 ID 填入 Step 6 常量
7. **审核策略**：首次提审只放免费功能，过审后再灰度开放测算与支付；付费文案用"传统文化解读服务"
8. **冷启动**：小红书/抖音发「X 月领证吉日盘点」「2026 搬家吉日」类内容吃搜索流量；海报分享是主要裂变路径
