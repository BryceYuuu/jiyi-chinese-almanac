# 今日吉历 V2 产品开发文档（简化版）

## 1. 产品定位

产品名：今日吉历

一句话定位：

> 年轻人的每日生活指南，用传统历法做底层，用现代语言告诉用户今天适合做什么。

核心理念：

-   不做传统黄历工具
-   不做"算命"产品
-   不做复杂命理展示
-   面向年轻用户，用大白话解释传统文化

默认模式：

### 友好版（默认）

面向普通用户。

展示：

-   今天适合什么
-   今天不太适合什么
-   今日节奏
-   今日灵感
-   推荐行动

### 专业版（可切换）

面向传统文化爱好者。

展示：

-   宜
-   忌
-   冲煞
-   值神
-   吉时
-   财神方位

# 2. V1 功能范围（砍掉50%）

## 保留功能

### 今日

核心首页。

内容：

-   日期
-   今日状态
-   今日适合
-   今日不太适合
-   一句话提醒
-   今日灵感
-   查看传统黄历

### 好日子

替代原"择吉"。

用户场景：

-   结婚
-   搬家
-   提车
-   出行
-   开业

流程：

选择事项 → 选择时间范围 → 推荐日期

结果展示：

日期 + 推荐指数 + 大白话解释。

### 今日灵感

替代原每日一签。

展示：

-   今日关键词
-   一句话解读
-   今日行动建议

保留传统签文入口。

### 我的

包含：

-   用户信息
-   历史记录
-   收藏
-   模式切换
-   设置

# 8. 技术方案

保持：

前端：

微信小程序原生 WXML/WXSS/JS

后端：

微信云开发

历法：

lunar-javascript

AI：

DeepSeek API

用途：

-   今日灵感生成
-   文案辅助

原则：

所有历法数据由 lunar-javascript计算。

AI不能生成历法。

# 10. 产品目标

第一阶段目标：

不是赚钱。

而是验证：

用户是否愿意每天打开一次。

核心指标：

-   次日留存
-   分享次数
-   好日子查询次数

后续再考虑：

-   AI深度解读
-   会员
-   付费报告
